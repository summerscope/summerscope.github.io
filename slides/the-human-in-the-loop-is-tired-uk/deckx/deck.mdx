### Slop or not? (A)

```python
import time
def retry(fn, attempts=3, base_delay=1.0):
    for attempt in range(attempts):
        try:
            return fn()
        except Exception:
            if attempt == attempts - 1:
                raise
            time.sleep(base_delay * 2 ** attempt)
```
