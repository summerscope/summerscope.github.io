# Say hi to Satyrn

Laura Summers — 28-slide Reveal.js deck, 16:9, plain white and black.

Open `index.html` in a browser. All presentation assets are local; external links need internet access. Arrow keys move through slides. `Esc` shows the overview. `N` toggles notes inside the page. `S` opens Reveal's speaker view when browser permissions allow it. `speaker-notes.md` follows the same slide order. `demo-commands.txt` contains the five exact benchmark prompts as ready-to-run Ollama commands.

The recorded GPT baseline appears before the live Satyrn comparison. The local-model demo slides contain the exact prompts; their outputs are not fabricated. The separate Engine section explains a published experiment, with its setup and results.

`assets/benchmark-chart.svg` and `summary.csv` contain the completed 30-run GPT baseline. The protocol and runtime record are alongside them. `benchmark-README.md` is the original experiment report; its full raw-response and scoring bundle is separately available as `satyrn-benchmark-results.zip`.

Sources and supporting details are in each slide's notes. The brand image is the actual Satyrn website social-preview asset. The initial-group photo is from the same project repository. Reveal.js 5.2.1 is reused from this repository's existing deck distribution.
