not the full picture

If you use a hosted model it's a tradeoff

training data, model config, guardrails → invisible

Hosted model = not the full picture. Not shaming — reality. At least know what's missing.

Measuring the system

  • observability / tracing
  • online & offline evals
Look at logs, traces — the data your system produces (outputs AND telemetry). Pick OTel-based tools; vendor magic that locks you in is the anti-pattern. Online + offline evals.

Technical balms

  • pre-mortems
  • AGENTS.md from your review comments
  • permission to just write the code
Pre-mortem: "assume it failed, why?" — use as a prompt. Review comments → AGENTS.md (careful: over-stuffing context). Permission to just write code — you don't have to use these 24/7.

Brain-friendly output

respect your cognitive limit (~4–7 chunks)

Aimee — chunk it; ask for a "scientific-abstract" not an "executive summary"; bold first/last sentences to speed-read.

Chunk it

  • Short paragraphs (2–3 sentences)
  • Plain words ("explain it like I'm five")
  • HTML header hierarchies (H1, H2…)
  • Spacing (e.g. <br>)
  • Bullet lists (like this one)
  • Caveman-mode replies — no filler (juliusbrussee/caveman)

Aimee Gonzalez-Cameron — "Good Words: Taking Care of Your Brain"

Aimee Gonzalez-Cameron (evaluation science = real academic discipline). Terminal = terrible for reading, get out. Caveman skill = zero-filler mode. We're not lemmings, not goldfish — learn from other disciplines.
